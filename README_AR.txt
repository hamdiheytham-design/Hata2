Driver Pro V3.6.6 — مشروع Android
================================

هذه الحزمة مخصصة لمستخدم واحد على الهاتف، ولا تتضمن نظام حسابات أو مدير أو صلاحيات متعددة.

المزايا الموجودة في المشروع:
- لوحة عدادات بطابع الشاحنات الأمريكية، خلفية داكنة وإضاءة زرقاء وإبرة حمراء/خضراء.
- عداد الطرود اليومية من 0 إلى 200 على اللوحة، مع تسجيل العدد الفعلي في السجل.
- تسجيل الطرود والمداخيل بشكل منفصل، والرحلات والمركبات.
- تسجيل الوقود والمصاريف والصيانة وحساب استهلاك الوقود والتنبيهات.
- صفحة مستقلة لإدارة الديون: تسجيل أصل الدين، الدفعات، المدفوع والمتبقي، مع حفظ السجل.
- عداد وقود صغير بجانب عداد الطرود، يُحدّث يدوياً من 0 إلى 100% ويحفظ القيمة على الهاتف.
- تقارير حسب الفترة وتصدير CSV ونسخ احتياطي/استرجاع JSON.
- حفظ محلي على الهاتف باستخدام Android SharedPreferences، مع ترحيل البيانات القديمة من localStorage عند توفرها.
- واجهة عربية وفرنسية وإنجليزية.
- GPS عبر خدمة Android أمامية مع إشعار دائم أثناء التتبع، وتسجيل النقاط محلياً.
- حفظ أماكن مفضلة وتنبيه وصول. الملاحة الفعلية تفتح تطبيق الخرائط الخارجي.

الإنترنت:
- إدخال البيانات وحفظها والرحلات اليدوية وGPS بالأقمار الصناعية لا تتطلب اتصالاً بالإنترنت.
- عرض خريطة OpenStreetMap وطبقات Leaflet يتطلب الإنترنت في هذه النسخة؛ لا توجد خرائط Offline مدمجة.
- فتح التوجيه في تطبيق الخرائط الخارجي قد يتطلب الإنترنت.

ملاحظات GPS مهمة:
- يلزم منح إذن الموقع الدقيق وتشغيل خدمة الموقع لاستخدام GPS بالأقمار الصناعية بصورة أفضل.
- قد تتأثر الخدمة بإعدادات البطارية والشركة المصنّعة للهاتف. اختبرها على الهاتف قبل الاعتماد عليها.
- المسافة تقديرية وليست بديلاً عن عداد المركبة أو أداة قياس قانونية.
- لا تعتمد على تنبيه الوصول وحده للسلامة أثناء القيادة.

البناء:
- التطبيق: versionName 3.6.6 / versionCode 17.
- يتطلب Java 17 وGradle 8.9 وAndroid SDK 35.
- GitHub Actions في .github/workflows/build.yml يبني Debug APK عند Push إلى main أو عند تشغيل workflow يدوياً.
- بعد نجاح البناء، حمّل Artifact باسم Driver-Pro-V3.6-APK من صفحة Actions.

حدود التحقق:
- تم فحص صياغة JavaScript بـ Node.js، وبنية ملفات المشروع وملف Workflow.
- لم يتم بناء APK فعلياً في هذه البيئة، ولم يتم اختبار الأذونات أو GPS على هاتف Android حقيقي.
- هذه حزمة مصدر قابلة للبناء والاختبار وليست APK نهائياً معتمداً.


إصدار 3.6.6: تحديث تصميم لوحة القيادة لمطابقة المرجع المعتمد، مع إبقاء البيانات والوظائف الحالية. مؤشرات السرعة وRPM تعرض شرطة (—) لعدم وجود حساس/مصدر بيانات فعلي، وحرارة المحرك تظهر عند إدخالها يدوياً.


إصدار 3.6.6: تحويل مقياس حرارة المحرك بصرياً إلى مؤشر تذكير تغيير الزيت من 0 إلى 8000 كم. يسجل المستخدم مسافة اليوم مرة واحدة، وتتراكم المسافات حتى 8000 كم، مع تنبيه وإعادة ضبط بعد تغيير الزيت وحفظ سجل التغييرات. المؤشر ليس حساس حرارة حقيقياً.
